# YHViewer v0.2.0

First public release: an offline Android reader for AI-generated HTML, Markdown and code, with TXT and EPUB support.

- HTML runs inside a restricted WebView; external links leave the app only after a user tap.
- Markdown renders offline with syntax highlighting and Paper, Ink, Terminal and Auto themes.
- Code pages include line numbers, copying without gutters, a wrap toggle and compact JSON formatting.
- TXT supports encoding detection, chapter navigation and UTF-8 private copies.
- EPUB supports chapter navigation and embedded resources, with archive limits, traversal/entity checks and JavaScript disabled.
- A local shelf keeps recent files, favorites and saved chapter/scroll positions. Imported copies remain readable after their source is deleted.

## Download and installation

Download `yhviewer-v0.2.0.apk` and `SHA256SUMS.txt` below. Requires Android 8.0 (API 26) or later. Android may ask you to allow installation from the browser or file manager used to open the APK.

- Application ID: `io.github.zer0rin.yhviewer`
- Version code: `3`
- Signing certificate SHA-256: `7d04d1564661330df2029624151d50826c3bcc0ada217d77b5889ae411ef1794`
- Final APK declares no `INTERNET` permission.

Check the downloaded APK against the attached checksum file (`sha256sum -c SHA256SUMS.txt` on Linux, or `shasum -a 256 yhviewer-v0.2.0.apk` on macOS).

Development builds with ID `com.example.yhviewer` remain separate apps; their shelves are not automatically transferred. Future official updates must use the same application ID and signing key. Keep any existing shelf before replacing a build signed with a different key.

## Known limits

External resources/CDNs are blocked. Standalone HTML cannot read sibling resources without folder authorization. Big5 detection is heuristic; DRM and interactive EPUB features are unsupported. Saved scroll ratios preserve an approximate reading position.
