# YHViewer v0.8.0

版本 **0.8.0 / versionCode 9**，数据库保持 v5。提供正式签名的 Standard 和 Strict APK 及 `SHA256SUMS.txt`，支持覆盖安装此前正式版。

## 大 TXT 索引秒开

- 导入时建立章节字节索引，打开时读取索引，正文按需加载，不再每次全文解码、切章。旧书缺少有效索引时首次打开补建一次；已有有效索引继续使用。
- 切章结果兼容旧版，保留原有章节号和阅读位置；修复逐候选标题重复处理全文的耗时，并保留 Android Unicode 空白语义。
- 同一30,665,783字节、4000章样本在API37模拟器上的仓库计时：导入含索引从约29秒降到1.3–1.4秒，缺索引重建从约30秒降到0.7秒；已有索引打开约64–66毫秒。这些不是所有手机的冷启动速度承诺。

## 章节连续滚动与实时排版

- TXT、EPUB 默认连续滚动，上下滑动自然跨章，章节间以淡点线分隔；标题、章节号、目录在读标记和保存位置随滚动更新。
- Aa 中调整主题、字体和字号即时生效，保留当前 WebView 和阅读锚点；可关闭“章节连续滚动”，恢复一章一页。
- 搜索、书签和目录可跳转到指定章节与位置；修复连续模式的 EPUB 内链、短章续读、边界位置恢复和提前打开查找的暂停状态。

## 目录快速滚动条

目录显示40章及以上时，右侧出现快速滚动条；按住拖动显示章节号和标题，可快速定位。筛选后仍显示原始章节号。

## 已知限制

- TXT 导入上限仍为32MiB。旧书缺少有效索引时首次打开仍需建索引，实际耗时取决于内容和设备；少数没有普通换行、仅用特殊 Unicode 行分隔符的极端文件仍可能较慢。
- 查找栏打开期间暂停自动补章，关闭后恢复。
- 连续窗口最多保留五章；五个短章不足一屏时，窗口末尾会留出续读空间。
- 原本竖排的 EPUB 仍转为横排显示。
- 图片尺寸尚未解析时按当前高度布局，解析后补偿位置；大图可能触发后续布局调整。
- 书籍脚本和事件处理器继续禁用；可信外层脚本只负责布局与受控章节导航。
