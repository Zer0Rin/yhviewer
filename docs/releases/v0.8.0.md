# YHViewer v0.8.0（候选）

版本 **0.8.0 / versionCode 9**，数据库保持 v5。本文件是候选发布说明，PR #8 尚未合并，未发布正式 v0.8.0。[v12 签名测试包](https://github.com/Zer0Rin/yhviewer/releases/tag/pr-8-test-v12) 可覆盖安装。

- v12 修正标题匹配的输入范围并保留 Android Unicode 空白语义。同一约30MiB/4000章样本的模拟器仓库计时：导入约1.3–1.4秒，缺索引重建约0.7秒；已有有效索引不清除。这不是手机冷启动速度承诺。
- 大 TXT 导入时建立章节字节索引，后续打开读取索引，正文按章节加载并缓存最近八章。旧书第一次打开补建索引；切章结果兼容旧版，保留原有阅读章节。TXT 导入上限仍为 32MiB。
- TXT、EPUB 默认连续滚动，跨章节时更新标题、目录在读标记和保存位置；同时最多保留五章。Aa 中可关闭“章节连续滚动”，恢复一章一页。
- 连续模式下字号、主题即时更新，保留当前 WebView 与阅读锚点。章节末尾和分隔区的位置用兼容旧进度格式的可选字段保存；书签也能返回这些位置。
- 目录达到 40 章时显示快速滚动条，按住拖动显示章节号和标题；筛选后仍显示原始章节号。
- 书籍脚本、事件处理器继续禁用；可信外层脚本只负责章节布局。书籍不能改变外层页面或越过原有资源策略。

已知限制：查找栏打开时暂停自动补章，关闭后恢复；原本竖排的 EPUB 仍转横排；大图加载前按当前内容高度布局，加载后补偿位置。五个短章不足一屏时，窗口末尾会留出续读空间，以保持五章上限并让读者继续向后滚动。

Android 性能数据、测试结果和截图见 [候选验证记录](../verification/V08_VERIFICATION.md)。桌面 JVM 的速度估算不代表手机实测。
