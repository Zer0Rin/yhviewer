# YHViewer v0.7.0

本次发布整合 v10 的多文件与文件夹导入、文内与全书搜索、书签，以及 EPUB 和 SVG 阅读改进。版本为 **0.7.0 / versionCode 8**。

## 导入文件与文件夹

- “＋ 打开”可一次选择多个文件，也可导入整个文件夹；单选仍直接打开，多选留在书架并显示导入结果。支持从文件管理器分享多个文件。
- 文件夹中的 HTML、Markdown 和相对路径图片、CSS 等资源一起保存，保留目录结构，网页间的相对链接可继续使用。重新导入时保留原记录的阅读进度、分组和收藏；编辑保存后仍能读取同目录资源。
- 显示导入进度，以及成功、资源、跳过和失败报告。对文件大小、数量、目录深度、实际复制字节和提供方元数据设置限制。
- 单独导入的网页缺少同目录资源时，显示缺失提示并建议改用“导入文件夹”。

## 查找和全书搜索

- 所有文档支持原生文内查找、高亮和上一个/下一个命中；EPUB 禁用网页脚本时也能查找。SVG 源码可在源码视图查找。
- TXT、EPUB 支持跨章节全书搜索，列出章节与上下文片段，最多显示 500 条结果；选择结果可跳到对应章节的指定命中。
- 修复 TXT 章节标题与正文命中序号不一致，以及页面重建后查找状态丢失的问题。

## 书签

- TXT、EPUB 可在 Aa 阅读设置中添加当前位置，在目录抽屉的“书签”页跳转或删除；单章书也保留此入口。
- 单页文档可从“⋯ → 书签”添加、跳转和删除。退出重开后仍保留位置，同章相近位置会去重，删除文档时同时清理书签。
- 数据库从 v4 升级到 **v5**，新增书签表，保留原有书架和阅读数据。

## EPUB、SVG 和其他格式

- 识别原本竖排的 EPUB，提示并转换为横排显示，使上下滚动、进度和翻页继续可用。本版不提供保持原始竖排布局的阅读模式。
- SVG 默认以图片显示，可在菜单切回源码；图片视图不执行 SVG 脚本，也不加载外部资源。
- Markdown 支持脚注；LOG 文件归入“纯文本”。
- 网页 alert、confirm、prompt 使用标注文档来源的 App 对话框；连续弹窗时可屏蔽后续提示，网页不能阻止离开。
- 修复共享文件夹副本重导入/编辑时的文件保留问题，并限制缺失资源诊断的内存和通知增长。

## 验证与升级

- 两个版本各 222 个单元测试通过；完整 API34 模拟器测试 Strict 127/127、Standard 136/136 通过。真实 30 例测试包在两个版本的专用模拟器上通过验收。
- 用户已确认正式签名 0.7.0 候选包覆盖安装后的真机验收通过：升级、文件夹导入、H02 资源、H04 弹窗、查找和全书搜索、书签、竖排 EPUB、SVG、脚注、多选和分享导入均正常。
- 正式发布产物另经签名、版本、APK 权限和优化包启动检查。

下载 **yhviewer-v0.7.0-standard.apk**（文档联网授权和内置 Python）或 **yhviewer-v0.7.0-strict.apk**（无 INTERNET 权限、不含 Python 运行时）。两个版本使用同一 applicationId 和正式签名，可直接覆盖旧正式版，无需卸载；二者不能同时安装。附 **SHA256SUMS.txt** 校验下载完整性。
