# YHViewer 1.0.0

YHViewer is a sandboxed Android reader for HTML, Markdown, code, TXT and EPUB, with Strict and Standard editions.

- Import multiple files, folders or shared documents; organize the shelf with groups, selection, filters and covers.
- Read continuously, open large TXT files with byte indexes, navigate chapters with the fast TOC scroller, search and save bookmarks.
- Adjust typography live with Aa and paper, ink or terminal themes, with glass controls and refined reading gestures.
- Edit documents and run JavaScript; Standard also bundles Python and supports explicit per-document network grants. Strict has no INTERNET permission or Python runtime.
- Includes the device-tested encoding, chapter navigation, Markdown defaults, footnote positioning and code-copy fixes.

## Known limitations

- In continuous mode, if the final chapter is very short and follows a large image, selecting that chapter in the TOC may stop in the previous chapter. Single-chapter mode works normally.
- Continuous mode does not append chapters while the find bar is open.
- Vertical EPUB text is rendered horizontally.
- Original HTML preserves its own theme; font size can be adjusted.
