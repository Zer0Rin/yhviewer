# YHViewer v0.6.0

本次发布合并了此前未单独发布的 v0.4、v0.5，以及 v0.6 的应用图标更新。

## v0.4：书架整理与长篇阅读

- **EPUB 封面与作者**：导入时读取书中声明的封面并生成约 300px 宽缩略图，限制异常图片解码尺寸；已有 EPUB 会在启动后补查封面。无封面书籍和 TXT 使用由书名决定配色的排版封面。搜索支持作者。
- **分组**：新建、重命名和删除分组，一份文档最多属于一个分组。删除分组只让文档回到“未分组”，保留文件与阅读进度；分组名检查空白、长度、重名和保留名称。
- **多选**：长按进入多选，支持移到分组、新建分组并移入、批量收藏/取消收藏、确认后删除；单选时可打开详情。
- **内容分类**：根据文件开头的内容区分网页、笔记、代码、数据、小说、电子书和纯文本，可与分组叠加筛选。旧文档在启动后补分类；分类不改变原有阅读器与权限规则。默认仍按最近打开排序。
- **目录抽屉**：TXT/EPUB 从左侧打开可滚动目录，定位并高亮当前章、淡化已读章节；超过 20 章可筛选，输入数字直达章节。只通过“目录”按钮打开，保留边缘翻页与系统返回手势。
- **沉浸阅读修复**：整页铺阅读主题底色，修复刘海区域露白；顶栏、底栏和目录跟随阅读主题。
- **数据库升级**：迁移至 v4，增加作者、封面检查状态、分组与分类信息。

## v0.5：统一主题与书架视觉

- **统一配色**：纸张、墨色、终端及自动主题贯穿书架、面板、对话框、编辑器和阅读界面；原生组件与网页主题颜色保持一致。
- **系统栏修复**：关闭三键导航栏的对比度遮罩，修复底部白带；在书中切换主题后返回书架，状态栏和导航栏图标使用当前主题颜色。
- **三列封面墙**：书籍默认使用三列封面网格，可切换列表并记住选择；文档保持紧凑列表。“继续阅读”保留大封面、进度和操作入口，并显示保存的章节号。
- **排版和控件**：移除 Bodoni，书名/章节名使用系统衬线体，文件名和界面数字使用清晰的界面字体。细线分隔、点状搜索底线和阅读进度、短线标签、圆润操作控件及按压反馈。
- **浮动胶囊**：章节栏和多选栏使用不透明主题底色，避免下方文字透出；两倍字号下操作仍可用，长书名不会挤掉“继续阅读”按钮。
- **细节**：一分钟内显示“刚刚”，`night-train` 等文件名显示为空格分隔；进度支持无障碍语义，次要文字与动作颜色改善对比度。
- **截图更新**：使用虚构示例文档展示封面、分组、多选、目录抽屉和各主题。

## v0.6：应用图标

- 新的 **A 版“V 撑起眼睛”** 矢量图标：深墨色底、米白眼睛、强调色 V，支持自适应启动器遮罩。
- 增加 Android 13+ 单色主题图标，由支持的启动器随壁纸配色。
- 移除十张旧模板 WebP 图标；README 使用同款 SVG 图标。
- 版本号为 **0.6.0 / versionCode 7**。

## 下载与升级

- **Strict**：`yhviewer-v0.6.0-strict.apk`，无 INTERNET 权限，不包含 Python 运行时。
- **Standard**：`yhviewer-v0.6.0-standard.apk`，支持明确授权的文档联网和内置 Python。
- **SHA256SUMS.txt**：两个 APK 的 SHA256 校验和，可使用 `sha256sum -c SHA256SUMS.txt` 检查下载完整性。

两个版本沿用正式 applicationId 和签名。升级请直接覆盖安装，保留书架和阅读进度，无需卸载。用户已确认此前 Standard 候选真机验收通过；新图标和本次正式产物另经构建、资源检查及优化 APK 模拟器启动验证。
