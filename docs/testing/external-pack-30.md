# 外部测试包（30 例）对照

来源：一位朋友在真机上使用 v0.6.0 后提供的"Android 书架测试文件 30 例"（6 类，每类 5 个；合成内容，不含个人数据）。
他反馈的两个问题：**不能多选导入或按文件夹导入**；**繁体 HTML（H02）的样式和图片不显示，调整权限也不行**。

下表是按源码和测试包内容逐个分析的结果，"v0.7"列是本次改动后的预期，需要在真机上按 `测试记录.csv` 复核。

## 导入方式

| 测试点 | v0.6 | v0.7 |
|---|---|---|
| 单文件导入 | 支持 | 支持 |
| 批量导入（系统选择器多选） | 不支持 | 支持；单个失败不影响其他文件，结束后显示导入报告 |
| 目录导入 | 不支持 | 支持；HTML / Markdown 和同目录资源一起复制，其他文档单独上书架，zip 等跳过并写进报告 |
| 分享导入（多个文件） | 不支持 | 支持（`ACTION_SEND_MULTIPLE`） |

## 测试包里检查、而 v0.6 没有的功能

| 测试点 | v0.6 | v0.7 |
|---|---|---|
| 搜索末尾标记（`H02-END` 等） | 无文内搜索 | 所有文档页内查找（高亮、上下跳转）；TXT / EPUB 全书搜索，点结果跳到对应章节的对应位置 |
| 书签 | 只有自动保存的阅读位置 | 手动书签：书在目录抽屉的"书签"页，单页文档在"⋯ → 书签" |
| 选中复制、字号主题、横竖屏、进度恢复 | ✓ | ✓ |

本仓库用 JVM 测试复现了其中可离线验证的部分：`V10ImportSearchTest.friendsPackIsPlannedSensibly` 用测试包的目录结构验证文件夹导入的分类；`EpubVerticalTest` 覆盖竖排识别。
用测试包里的 5 个 EPUB 实际运行解析器：E04 识别为竖排，E02 识别到封面，五本都能全书搜索到 `Exx-END`。
